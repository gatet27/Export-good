Export catalogue

Récupère les noms, liens et images des produits publics dans une archive ZIP.

Si le navigateur bloque l'accès, ouvre le catalogue JSON public, enregistre-le puis importe-le ici.

Les fichiers externes peuvent être bloqués par CORS. Les images non récupérées restent référencées dans le manifeste. Utilise uniquement les ressources que tu es autorisé à réutiliser.
